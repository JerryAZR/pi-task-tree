# Task-Related Tools Available

## Tools List

The following task management tools are available:

1. **task_create_root** - Create a new task list (root) with initial tasks
2. **task_list** - Show tasks in focus or full mode
3. **task_get** - Get details of a planned task by index or title
4. **task_update** - Update title or description of a planned task
5. **task_close** - Mark a task as completed or delete it
6. **task_extend_root** - Add tasks to the root level of the active plan
7. **task_breakdown** - Add subtasks under an existing parent task

## Summary

All tools follow the naming convention `task_*` and provide a complete task management workflow:
- Create → List → Get → Update → Break down (subtasks) → Close
