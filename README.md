# pi-task-tree

Nested task list with parallel groups and focus mode for pi.

## Installation

```bash
npm install pi-task-tree
```

## Usage

```typescript
import { TaskManager } from 'pi-task-tree';

const manager = new TaskManager();
```

## API

See the [docs](./docs/) directory for detailed API documentation.

## Development

```bash
# Run tests
npm test

# Watch mode
npm run test:watch

# Build
npm run build
```
